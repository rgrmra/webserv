Webserv Configuration Directives

autoindex

  • Syntax: autoindex on | off;
  • Default: autoindex off;
  • Context: http, server, location
  • Enables or disables the directory listing output.

    • client_max_body_size

  • Syntax: client_max_body_size size;
  • Default: client_max_body_size 1M;
  • Context: http, server, location
  • Sets the maximum allowed size of the client request body. If the size in a request exceeds the configured value, the 413 (Payload Too Large) error is returned to the client. Please be aware that browsers cannot correctly display this error. Setting size to 0 disables checking of client request body size.

    • error_page

  • Syntax: error_page code ... uri;
  • Default:
  • Context: http, server, location
  • Defines the URI that will be shown for the specified errors. 
    error_page 404             /404.html;
error_page 500 502 503 504 /50x.html;
    This causes an internal redirect to the specified uri.

    • fastcgi_pass

  • Syntax: fastcgi_pass path;
  • Default:
  • Context: location
  • Defines the path to the CGI binary that will handle CGI requests. 
    fastcgi_pass /usr/bin/php-cgi;

    • fastcgi_extension

  • Syntax: fastcgi_extension extension ...;
  • Default:
  • Context: location
  • Specifies the file extensions that should be processed by the CGI binary defined in fastcgi_pass. 
    fastcgi_extension php;

    • http

  • Syntax: http { ... }
  • Default:
  • Context: main
  • Provides the configuration file context in which the HTTP server directives are specified.

    • index

  • Syntax: index file ...;
  • Default: index index.html index.html;
  • Context: http, server, location
  • Defines files that will be used as an index.

    • limit_except

  • Syntax: limit_except method ... { ... }
  • Default: limit_except GET { deny: all; }
  • Context: location
  • Limits allowed HTTP methods inside a location. The method parameter can be one of the following: GET, POST or DELETE.

    • listen

  • Syntax: listen ip:port;
  • Default:
  • Context: server
  • Defines the IP address and port for the virtual server. If one is missing, defaults are used (0.0.0.0 and 8080), but both cannot be omitted. 
    listen 9000;
listen 127.0.0.1;
listen 127.0.0.1:9000;

    • location

  • Syntax: location path { ... }
  • Default: location / { ... }
  • Context: server
  • Applies configuration based on the request URI.
    The server normalizes paths, resolving sequences like /example/../example to /example.

    • return

  • Syntax: return code text | URL;
  • Default:
  • Context: server, location
  • Stops processing and returns the specified code to a client or redirect to an URL.

    • root

  • Syntax: root path;
  • Default: root ./var/www/html;
  • Context: http, server, location
  • Sets the root directory for requests. For example, with the following configuration
    The /data/w3/i/top.gif file will be sent in response to the /i/top.gif request.

    • server

  • Syntax: server { ... }
  • Default:
  • Context: http
  • Sets configuration for a virtual server.

    • server_name

  • Syntax: server_name name ...;
  • Default:
  • Context: server
  • Sets names of a virtual server, for example: 
    server_name example.com www.example.com;
    The first name becomes the primary server name.

    • web_dav

  • Syntax: web_dav on | off;
  • Default: web_dav off;
  • Context: http, server, location
  • Enables WebDAV support for the POST and DELETE methods, allowing direct file uploads and deletions.
