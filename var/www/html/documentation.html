Nginx Configuration Directives

absolute_redirect

Syntax: absolute_redirect on | off;
Default: absolute_redirect on;
Context: http, server, location
Introduced in: 1.11.8

If disabled, redirects issued by nginx will be relative instead of absolute URLs.

client_max_body_size

  • Syntax: client_max_body_size
  • Default: client_max_body_size 1M;
  • Context: http, server, location
  • Sets the maximum allowed size of the client request body. If the size exceeds the configured value, the 413 (Request Entity Too Large) error is returned.
